# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 站点时钟漂移裁决（甲-切流账册）

- 形态：单流质控入栏，**不做双写双轨**。装载闸口按栏规 `站钟漂移阈秒`（默认 604800 秒）裁决。
- 可信点（漂移 ≤ 阈）→ 正式进 `入栏缓冲`；超阈偏钟点 → 带 `偏钟超阈:漂移Xs>阈Ys` 指纹进 `坏点匣`，报文命运 `已偏钟`，同票写 `站钟偏移裁决` 账册。
- 同成同败：阈读取在装载事务内，阈缺失/损坏 → 整批回滚，不写一行业务数据。
- 互斥：进程内装载锁 + `BEGIN IMMEDIATE`，混灌并发双请求下偏钟点不可能双成功或混入现行缓冲。
- 只读接口：`GET /api/站钟偏移裁决`、`GET /api/站点源/对账`（含偏钟点的站点结论为“偏钟旁路”，不假绿）。
- 页面：站点源、报文流、入栏缓冲、坏点匣、栏规、探栏台均可见漂移裁决；演示动作 `POST /api/演示/偏钟混灌`。
- 并发核验：`python -I scripts/偏钟并发双请求.py [--http]`。
